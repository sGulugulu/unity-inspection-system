# 巡检交互修复记录

日期：2026-10-30。

- 标记使用射线精确命中点，不再沿世界 Y 轴抬高，也不创建会被射线击中的球体碰撞器。
- 标记通过世界坐标投影绘制为小图标；鼠标悬停显示标题和描述。场景启动时从后端加载历史问题。
- 增加四周墙面，不生成天花板。
- 表单显示并允许修改 X/Y/Z，初始值是表面命中点；有效修改同步图标。拒绝空值、非数字、非有限值及超出 ±100000 的坐标。
- 表单区域拦截场景点击；填写时暂停 WASD 和鼠标视角控制，避免输入文字引起相机移动。
- 提交时禁用重复操作并显示等待提示；请求超时为 15 秒。失败保留内容，成功保留已保存标记，反馈独立于表单显示。
- 取消填写移除未提交标记。

自动化验证通过 Unity 批处理执行 `InspectionRegressionChecks.Run`，覆盖合法和非法坐标、模型表面射线命中及投影往返一致性。日志位于工作区 `unity-regression.log`。此验证同时会触发 Unity 编译。

仍需人工确认：Game 窗口内悬停提示的布局、不同窗口大小下表单和图标的可见性，以及真实提交时成功与失败提示的视觉效果。标记采用屏幕投影，目前不执行遮挡剔除，墙体后方的标记也可能显示。
